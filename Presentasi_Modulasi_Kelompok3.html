Kenapa materi ini penting?
03

Setiap jaringan nirkabel harus memilih cara membawa bit.

Wi‑Fi, 4G/5G, Bluetooth, dan IoT sama-sama harus “membungkus” bit menjadi gelombang radio.

Tujuan pembelajaran

  • Memahami modulasi & pengkodean
  • Membedakan analog & digital
  • Menjelaskan channel coding
  • Mengaitkan spektrum dan performa

Contoh nyata

  • Dekat router → modulasi tinggi
  • Jauh/terhalang → modulasi diturunkan
  • 2.4 GHz luas, tetapi lebih ramai interferensi

Inti bahasan

  • Modulasi → bentuk gelombang
  • Coding → ketahanan error
  • Spektrum → jalur frekuensi

Modulasi analog
05

AM, FM, dan PM — lihat bentuk gelombangnya

AM · Amplitude

amplitudo berubah

Parameter: amplitudo · mudah dibuat · rentan noise.

FM · Frequency

kerapatan berubah

Parameter: frekuensi · lebih tahan noise · contoh: radio FM.

PM · Phase

posisi/fase berubah

Parameter: fase · dasar sistem digital · berkaitan dengan FM.

Pada AM, noise amplitudo langsung mengganggu pesan; FM relatif lebih aman karena pesan dibawa oleh perubahan frekuensi.
Modulasi digital
06

ASK, FSK, PSK: bit 0 dan 1 menjadi kondisi sinyal berbeda.

ASK

10110010

1 = amplitudo tinggi · 0 = amplitudo rendah.

FSK

10110010

1 = frekuensi f1 · 0 = frekuensi f0.

PSK

10110010

Bit diwakili fase · BPSK: 2 fase · QPSK: 4 fase.

Analogi: ASK = terang/redup, FSK = kedipan cepat/lambat, PSK = menggeser arah kedipan.

QAM
08

QPSK → 16‑QAM → 64‑QAM → 256‑QAM

Titik konstelasi bertambah, bit/simbol naik, tetapi jarak antartitik makin rapat.

QPSK
2 bit/simbol

4 titik konstelasi. Jarak titik relatif jauh sehingga lebih toleran terhadap noise.

Trade‑off

256‑QAM lebih cepat, tetapi membutuhkan sinyal lebih bersih karena titik konstelasi sangat rapat.

2 bit4 bit6 bit8 bit
Contoh ideal: 1 Msymbol/s × 2 bit/simbol = 2 Mbps (QPSK), sedangkan × 8 bit/simbol = 8 Mbps (256‑QAM). Belum termasuk coding/overhead.

Konsep pengkodean
10

Coding menambah “pengaman” data.

Bit redundan membantu penerima mendeteksi atau memperbaiki error.

Contoh parity bit

1011

Jumlah 1 = 3 (ganjil) → tambah parity 1 agar total genap.

10111

Tanpa coding

Bit salah langsung merusak data.

Dengan coding

Sebagian error dapat dideteksi atau dikoreksi.

Kenapa perlu?

Kanal udara punya noise, interferensi, dan fading.

Parity hanya contoh dasar. Sistem modern memakai LDPC, Turbo, dan Polar Code.
Coding Rate
11

Rate 1/2, 2/3, 3/4: proteksi vs efisiensi.

Coding rate = bit informasi / total bit yang dikirim.

Rate 1/2

INFORMASI
REDUNDAN

1 bit info → ±2 bit terkirim.
Proteksi kuat, overhead besar.

Rate 2/3

INFORMASI
REDUNDAN

2 bit info → ±3 bit terkirim.
Proteksi dan efisiensi sedang.

Rate 3/4

INFORMASI
REDUNDAN

3 bit info → ±4 bit terkirim.
Proteksi lebih sedikit, data lebih efisien.

Dalam AMC: sinyal lemah → rate lebih rendah; sinyal kuat → rate lebih tinggi agar throughput naik.
Jenis channel coding
12

Detection dan correction sering dipakai bersama.

Error Detection

  • Mendeteksi bahwa data rusak
  • CRC, parity bit
  • Validasi frame/paket
  • Jika error, paket dapat diminta ulang

Error Correction

  • Memperbaiki error otomatis
  • Reed‑Solomon, convolutional, Turbo, LDPC, Polar
  • Penting saat retransmisi mahal/lambat

Semakin tinggi frekuensi, kapasitas bisa meningkat — tetapi jangkauan umumnya makin pendek.

Licensed spectrum

Dipakai operator seluler melalui izin/regulasi.

Unlicensed spectrum

Spektrum Wi‑Fi
16

2.4 GHz vs 5 GHz vs 6 GHz

2.4 GHz

  • Jangkauan lebih luas
  • Penetrasi tembok baik
  • 20/40 MHz
  • Sering padat/interferensi

5 GHz

  • Interferensi lebih rendah
  • 20/40/80/160 MHz
  • Kecepatan lebih tinggi
  • Jangkauan lebih pendek

6 GHz

  • Wi‑Fi 6E/7
  • Channel hingga 320 MHz
  • Kepadatan relatif rendah
  • Butuh perangkat kompatibel
Rumah besar/banyak tembok → 2.4 GHz bisa lebih stabil. Streaming dekat router → 5/6 GHz bisa memberi throughput lebih tinggi.

Kapasitas Shannon
18

Bandwidth dan SNR membatasi kapasitas teoritis kanal.

C = B × log₂(1 + SNR)

C = kapasitas (bps) · B = bandwidth (Hz) · SNR harus dalam bentuk linear.

Contoh hitung cepat

B = 20 MHz
+
SNR = 10 dB
10 dB → 10^(10/10) = 10
C ≈ 20M × log₂(11)
≈
69 Mbps
Makna akademik: nilai dB tidak langsung dimasukkan ke rumus. Konversi dulu ke rasio linear.
SNR tinggi memungkinkan titik QAM lebih rapat → orde modulasi lebih tinggi.
OFDM
19

Banyak subcarrier sempit di dalam satu kanal besar.

OFDM membagi kanal lebar menjadi banyak subcarrier ortogonal sehingga sistem lebih tahan terhadap multipath.

Subcarrier bergerak dengan frekuensi berbeda, tetapi tersusun ortogonal.

Kenapa berguna?

Multipath membuat simbol saling mengganggu. Guard interval / cyclic prefix membantu menekan efeknya.

Tanpa OFDM

Satu carrier lebar lebih rentan fading selektif.

Dengan OFDM

Data dibagi ke banyak subcarrier.

Trade‑off: perlu sinkronisasi dan kontrol PAPR yang baik.
MIMO & Beamforming
20

Banyak antena → throughput, reliabilitas, dan arah sinyal.

Fase/amplitudo antar antena diatur agar sinyal menguat ke perangkat tujuan.

Spatial multiplexing

Beberapa aliran data dikirim paralel → throughput naik.

Diversity

Beberapa antena membantu menjaga koneksi saat fading.

Beamforming

Mengarahkan energi sinyal ke arah tertentu.

Contoh kampus ramai: AP dapat mengarahkan sinyal ke perangkat aktif dan mengurangi energi ke arah lain.

Quiz singkat

Laptop dekat router memakai 256‑QAM rate 3/4. Ketika pindah jauh dan SNR turun, apa yang sebaiknya dilakukan sistem?

AMC menurunkan orde modulasi — misalnya ke 64‑QAM, 16‑QAM, atau QPSK — dan memakai coding rate lebih rendah agar koneksi tetap stabil.
SNR 10 dB masuk rumus Shannon sebagai 10 linear, bukan 10 dB.
Untuk error berat, rate 1/2 lebih kuat daripada rate 3/4.
Kesimpulan
22

Tiga ide utama + dua penguat

1. Modulasi

Mengubah bit menjadi gelombang radio.

2. Coding

Menambah proteksi terhadap error.

3. Spektrum

Menentukan jalur frekuensi yang tersedia.

4. MIMO

Memakai banyak antena untuk kapasitas/reliabilitas.

5. Beamforming

Mengarahkan energi sinyal.

Pesan utama: performa jaringan nirkabel adalah keseimbangan antara bandwidth, SNR, modulasi, coding, MIMO/beamforming, dan manajemen spektrum.
